# Reference Projects

The purpose of these repositories is architectural inspiration only.

Do NOT copy code.
Do NOT replicate APIs.
Do NOT clone implementation details.

Instead, study their architecture, abstractions, design patterns, and developer experience.

The final design must combine the strongest ideas from these projects while remaining original.

---

https://github.com/deepseek-ai/deepseek-harness

- Plugin architecture
- Runtime lifecycle
- Capability registration

- Agent platform design
- Everything-is-a-plugin philosophy
